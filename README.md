IoT-Based Air Quality Monitoring System

 Overview
An IoT-based air quality monitoring system that measures environmental parameters and provides real-time information about air quality. The system uses sensors connected to an ESP8266 microcontroller.

 Technologies Used
- ESP8266
- MQ135 Gas Sensor
- DHT11 Temperature & Humidity Sensor
- OLED Display
- Arduino IDE
- Embedded C

 Features
- Real-time air quality monitoring
- Gas concentration detection
- Temperature measurement
- Humidity measurement
- OLED display
- IoT-enabled monitoring

 Working
1. MQ135 detects changes in air quality.
2. DHT11 measures temperature and humidity.
3. ESP8266 collects and processes sensor readings.
4. The measured parameters are displayed on the OLED.
5. The system can be extended for remote IoT monitoring.

 Future Scope
- Cloud data logging
- Mobile application
- Air-quality alerts
- Multiple environmental sensors
